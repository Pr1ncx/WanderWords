# WANDERWORDS

An interactive, premium digital travel magazine about 10 Indian destinations:
Srinagar, Manali, Amritsar, Jaipur, Agra, Goa, Munnar, Gangtok, Rann of Kutch and Shillong.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Optional sound

Add royalty-free `ambient.mp3` and `whoosh.mp3` to `public/audio/`. Missing files are ignored.

## Stack

Vite, three.js, GSAP and Lenis. All graphics are generated in code.
